# Locked dependencies of the Eliozo Flask app (generated from requirements.in).
#
#     python -m pip install -r requirements.txt
#
# Every package -- direct and indirect -- is pinned to an exact version, so an
# install never picks up a release published after these pins were made (a
# compromised or broken "zero-day" upload). The pins are the newest versions
# uploaded to PyPI before the cut-off below, 14 days before they were made,
# resolved with wheels only (no build scripts run during install).
#
#   cut-off:   2026-10-03T00:00:00Z   (pins made 2026-10-17)
#   checked:   Windows x64, Linux x86_64 (manylinux), macOS x86_64 and arm64;
#              Python 3.11 - 3.14; tests + app smoke test on macOS / 3.14
#
# Exceptions to "newest before the cut-off":
#   cryptography 48.0.1   newer releases have no wheels for Intel Macs
#
# Refreshing: in a fresh venv, with pip >= 26 and a new cut-off date C,
#     python -m pip install --only-binary :all: --uploaded-prior-to C -r requirements.in
#     python -m pip freeze
# then review the changes, re-check the platforms, run the tests, and keep
# the Windows-only pins at the end (pip freeze on macOS/Linux omits them).
